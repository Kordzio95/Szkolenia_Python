# Web 1 - Projekt strony accountant w HTML i CSS

## Co to jest, po ludzku
Sam wyglad strony do programu accountant, jeszcze bez Pythona (dane sa wpisane na sztywno, na przyklad).

- `index.html` - strona glowna: saldo, magazyn i 3 formularze (zakup, sprzedaz, zmiana salda z komentarzem)
- `historia.html` - podstrona z historia operacji (w aplikacji bedzie pod `/historia/` i `/historia/<od>/<do>/`)
- `static/style.css` - kolory, karty, tabele, przyciski, dziala tez na telefonie

## Jak zobaczyc
Wystarczy dwa razy kliknac `index.html`, otworzy sie w przegladarce.
